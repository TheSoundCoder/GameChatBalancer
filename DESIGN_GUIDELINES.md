# Design Guidelines

## Language
- The entire application UI language must be English.
- All labels, buttons, tooltips, section titles, status texts, and validation/error messages must be written in English.
- Do not mix English and German in the UI.

## Units and Formatting
- Use seconds for overlay display duration.
- Display duration values in the UI as `s` (for example: `3 s`).
- Do not use milliseconds (`ms`) for overlay duration in the UI.
